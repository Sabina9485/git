# Заметки по Git

## Git — основы
1. Git — локальная программа, история в папке .git
2. Три зоны: рабочая директория → staging → репозиторий
3. git status показывает, где что находится
4. Ветка — это ярлык на снимок, не копия файлов
5. git restore --staged убирает файл из staging, не трогая диск

## Git Flow — роли веток
1. main — только релизы, фичи напрямую не попадают
2. develop — интеграция следующего релиза
3. feature/* — одна задача, создаётся от develop
4. release/* — подготовка версии, вливается в main и develop
5. hotfix/* — срочный фикс прода, вливается в main и develop

## Таблица: ветка → откуда → куда → зачем

| Ветка | Откуда | Куда | Зачем |
|-------|--------|------|-------|
| main | — | — | Боевая/релизная линия |
| develop | от main при старте | — | Черновик следующего релиза |
| feature/* | от develop | в develop | Одна фича/задача |
| release/* | от develop | в main и develop | Подготовка релиза |
| hotfix/* | от main | в main и develop | Срочный фикс прода |
